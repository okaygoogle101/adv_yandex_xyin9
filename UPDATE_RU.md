# Обновление
1. Посмотрите VERSION.txt текущей установки/скачанного комплекта и описание нового релиза.
2. Закройте локальную игру и сохраните старые файлы для отката.
3. Скачайте полный `adv_yandex_xyin9.zip` из нужного релиза.
4. Скопируйте содержимое его cstrike в cstrike игры с заменой.
5. Не добавляйте повторно строку плагина в plugins.ini. Перезапустите игру и карту.

Название карты всегда `adv_yandex_xyin9`. Номер выпуска находится в VERSION.txt и названии релиза GitHub. При изменении BSP для игры на чужом сервере нужна точно такая же версия BSP, как там.
Для отката используйте полный комплект предыдущего релиза, включая его плагин и ресурсы.
